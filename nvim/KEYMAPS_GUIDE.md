## 1. 파일 네비게이션 (Harpoon)

Harpoon은 자주 쓰는 파일을 "마킹"해두고 번호로 즉시 점프하는 플러그인이다.
탭 바 없이 최대 4개 파일 사이를 순간이동할 수 있다.

### 사용 워크플로우

```
1. 작업할 파일을 연다 (Telescope로 찾거나 netrw로 열거나)
2. Space+a 로 현재 파일을 Harpoon 리스트에 추가
3. 다른 파일도 열어서 Space+a 로 추가
4. 이제 Ctrl+h / Ctrl+t / Ctrl+n / Ctrl+s 로 파일 1~4번 사이를 즉시 점프
```

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Space+a` | 파일 마킹 추가 | 현재 편집 중인 파일을 Harpoon 리스트에 등록 |
| `Ctrl+e` | Harpoon 메뉴 | 마킹된 파일 목록 확인, 순서 편집, 삭제 가능 |
| `Ctrl+h` | 파일 1번으로 이동 | 첫 번째 마킹 파일로 즉시 점프 |
| `Ctrl+t` | 파일 2번으로 이동 | 두 번째 마킹 파일로 즉시 점프 |
| `Ctrl+n` | 파일 3번으로 이동 | 세 번째 마킹 파일로 즉시 점프 |
| `Ctrl+s` | 파일 4번으로 이동 | 네 번째 마킹 파일로 즉시 점프 |
| `Shift+H` | 이전 마킹 파일 | 순환하며 이전 파일로 이동 |
| `Shift+L` | 다음 마킹 파일 | 순환하며 다음 파일로 이동 |

### 42 과제에서의 활용 예시

```
ft_printf 과제라면:
  1번 슬롯 → ft_printf.c (메인 함수)
  2번 슬롯 → ft_printf.h (헤더)
  3번 슬롯 → ft_format.c (서브 함수)
  4번 슬롯 → Makefile

Ctrl+h로 메인, Ctrl+t로 헤더, Ctrl+n으로 서브 함수를 즉시 왔다갔다
```

## 2. 파일 탐색 (Telescope)

파일을 처음 찾아서 열 때 사용한다. Harpoon에 마킹하기 전 단계.

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `Space+ff` | 파일 검색 | 프로젝트 내 모든 파일을 이름으로 검색 |
| `Space+fg` | Git 파일 검색 | git 관리 중인 파일만 검색 (빠르고 깔끔) |
| `Space+fb` | 버퍼 검색 | 현재 열려있는 파일들 중에서 검색 |
| `Space+fh` | 도움말 검색 | Neovim 도움말 태그 검색 |

## 3. 이동 & 스크롤 (ThePrimeagen 핵심)

코드를 읽고 이동할 때 커서가 화면 중앙에 유지되어 맥락을 잃지 않는다.

| 단축키 | 기능 | 왜 유용한가 |
|--------|------|------------|
| `Ctrl+d` | 반 페이지 아래 (중앙 유지) | 기본 Ctrl+d는 커서가 맨 아래로 가버림 → 중앙 고정 |
| `Ctrl+u` | 반 페이지 위 (중앙 유지) | 위로 스크롤해도 커서가 항상 화면 가운데 |
| `n` | 다음 검색 (중앙 유지) | /검색 후 n 누를 때 결과가 항상 화면 중앙에 |
| `N` | 이전 검색 (중앙 유지) | 역방향 검색도 동일 |
| `J` | 줄 합치기 (커서 유지) | 기본 J는 커서가 합쳐진 줄 끝으로 이동 → 원래 위치 유지 |

## 4. 코드 편집 (Visual 모드)

| 단축키 | 모드 | 기능 | 설명 |
|--------|------|------|------|
| `J` | Visual | 선택 블록 아래로 이동 | 여러 줄 선택 후 J로 통째로 아래로 밀기 |
| `K` | Visual | 선택 블록 위로 이동 | 여러 줄 선택 후 K로 통째로 위로 밀기 |
| `Space+s` | Normal | 현재 단어 전체 바꾸기 | 커서 위의 단어를 파일 전체에서 일괄 변경 (리팩토링) |
| `Q` | Normal | 비활성화 | 실수로 Ex 모드 진입 방지 |

## 5. 복사 & 붙여넣기 개선

Vim의 레지스터 시스템 때문에 발생하는 불편함을 해결한다.

| 단축키 | 모드 | 기능 | 언제 쓰나 |
|--------|------|------|----------|
| `Space+p` | Visual | 붙여넣기 (레지스터 보존) | 선택 영역 위에 붙여넣을 때 원본 복사 내용 유지 |
| `Space+y` | Normal/Visual | 시스템 클립보드 복사 | 다른 프로그램에 붙여넣을 내용 복사 |
| `Space+Y` | Normal | 줄 전체를 시스템 클립보드 복사 | 현재 줄 전체를 시스템 클립보드로 |
| `Space+d` | Normal/Visual | 삭제 (레지스터 오염 없음) | 지우기만 하고 레지스터는 건드리지 않음 |

### 레지스터 문제란?

```
일반 vim에서의 문제:
  1. yy로 코드 복사
  2. 다른 줄 선택 후 p로 붙여넣기
  3. 이때 선택했던 내용이 레지스터에 들어가버림
  4. 다시 p 하면 원래 복사한 게 아닌 방금 덮어쓴 내용이 나옴

Space+p를 쓰면:
  → 붙여넣기 해도 원래 복사한 내용이 레지스터에 그대로 남아있음
```

## 6. LSP (코드 인텔리전스)

C 파일 편집 시 clangd가 자동 연결되면 활성화되는 키맵들이다.

| 단축키 | 기능 | 설명 |
|--------|------|------|
| `gd` | 정의로 이동 | 함수/변수의 정의 위치로 점프 |
| `K` | 호버 정보 | 커서 위 함수의 시그니처, 설명 팝업 |
| `Space+vd` | 진단 정보 | 현재 줄의 에러/경고 상세 보기 |
| `Space+vca` | 코드 액션 | 자동 수정 제안 (include 추가 등) |
| `Space+vrr` | 참조 찾기 | 이 함수/변수가 어디서 쓰이는지 전부 보기 |
| `Space+vrn` | 이름 변경 | 변수/함수명을 프로젝트 전체에서 안전하게 변경 |
| `Space+vws` | 워크스페이스 심볼 | 프로젝트 내 모든 함수/구조체 검색 |
| `Ctrl+h` | 시그니처 도움말 | 함수 인자 입력 중 파라미터 힌트 (Insert 모드) |
| `[d` | 다음 진단 | 다음 에러/경고 위치로 점프 |
| `]d` | 이전 진단 | 이전 에러/경고 위치로 점프 |

## 10. 자동 기능 (autocmd)

사용자가 직접 호출하지 않아도 자동으로 동작하는 기능들이다.

| 기능 | 트리거 | 설명 |
|------|--------|------|
| 줄 끝 공백 제거 | 파일 저장 시 | Norminette 위반 자동 방지 |
| Yank 하이라이트 | 복사(y) 시 | 복사된 영역이 잠깐 번쩍여서 시각적 확인 |
| 프로젝트 루트 감지 | Neovim 시작 시 | Makefile, .git 등이 있는 곳을 자동으로 작업 디렉토리로 설정 |
| 80자 초과 경고 | 항상 | colorcolumn(붉은 줄) + 80자 넘는 글자 빨간색 표시 |

## 디렉토리 구조

```
~/.config/nvim/
├── init.lua                    ← 진입점 (require만 4줄)
└── lua/
    ├── options.lua             ← 기본 옵션
    ├── keymaps.lua             ← 플러그인 무관 키맵
    ├── autocmds.lua            ← 자동 명령
    └── plugins/
        ├── init.lua            ← lazy.nvim 부트스트랩
        ├── header.lua          ← 42header + norminette
        ├── lsp.lua             ← Mason + lspconfig + nvim-cmp
        ├── telescope.lua       ← 파일 검색
        ├── harpoon.lua         ← 파일 네비게이션 (핵심)
        ├── undotree.lua        ← undo 히스토리
        └── ui.lua              ← 테마 + treesitter
```
